☁️ Cloud Sync — JSONBin
Sync printed reports to JSONBin so any device can access them. Get a free API key at jsonbin.io → sign up → API Keys → create key.
🐙 Cloud Sync — GitHub Gist
Secondary backup sync to a private GitHub Gist. Create a token at GitHub → Settings → Developer settings → Personal access tokens → select gist scope. Then create a new secret Gist and paste its ID here.
📲 Telegram Notifications
Send a Telegram message to yourself every time a report is printed. Free, instant, no backend needed. Create a bot at @BotFather → /newbot → copy the token. Then message @userinfobot to get your Chat ID.
